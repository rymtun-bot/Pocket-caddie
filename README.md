# Pocket Caddie

On-course golf page for iPhone: GPS yards to greens you save, club suggestion from your own carry
distances, shot measuring, and a shot log you can copy out.

Open https://rymtun-bot.github.io/pocket-caddie/ in Safari, allow location, and Add to Home Screen.
All data (clubs, green locations, shots) stays in the phone's browser storage; nothing is uploaded.
